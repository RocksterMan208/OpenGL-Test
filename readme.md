
# Learning OpenGL for use in 3D development
### Voxel Engine

The program generates a 12x(up to)256x12 set of chunks which heights are randomized through the use of FastNoiseLite's Perlin noise function.
<br>The GUI on the screenshot/inside the program is handled via ImGUI.</br>

## To compile, have *make*, *glfw AND glm* installed then run:
```
make run
```
to compile.
